# My Portfolio

This is my personal portfolio website built with React to showcase my projects, technical decisions, and growth as a frontend developer.

The goal wasn't just to build a nice looking site, but to create a structured, scalable application that reflects how I approach problem-solving and frontend architecture.

## About This Project

Most portfolios focus heavily on visuals but don't communicate technical thinking clearly.

With this project, I wanted to:
- Present my projects with proper technical breakdowns
- Show how I structure React applications
- Keep the design clean and readable
- Build something scalable rather than static

This portfolio itself is treated as a real project — not just a langing page.

---

## Tech Stack

- **React**
- **JavaScript**
- **CSS**
- **React Router**

---

## Structure & Architecture

The application is structured into reusable components:
- Navigation
- Hero section
- Projects preview
- Dedicated project detail pages
- Footer

Each section was built with separation of concerns in mind, keeping layout, logic, and content organized.

Routing was implemented to allow each project to have its own detailed breakdown page.

---

## Key Features

- Clean and responsive layout
- Dedicated pages for in-depth project explanations
- Reusable UI components
- Structured content hierarchy
- Clear navigation flow
